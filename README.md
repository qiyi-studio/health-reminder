# 健康提醒程式 使用說明

## 這是什麼

一個在電腦上執行的桌面小工具，每隔固定時間（預設每小時）會跳出一個**強制性**的提醒視窗：

- 視窗一開始出現在螢幕正中區，之後可以拖曳自訂的標題列來移動位置，**若電腦連接多台螢幕，也可以把視窗拖到另一台螢幕上**；但無論在哪個螢幕上，視窗最下緣都不能碰到該螢幕工作列上緣，藉此限制移動範圍，讓使用者無法把視窗往下藏起來
- 視窗**沒有**系統標題列，因此沒有關閉鈕、也沒有縮小鈕
- 每項提醒都要手動按「完成」才算勾選；需要持續一段時間的項目（例如起身站立兩分鐘）要先按「開始」計時，時間到才能按「完成」，計時中也可以「暫停 / 繼續」
- 全部項目都完成後，視窗才會自動關閉
- **若提醒視窗跳出後 10 分鐘內沒有完成全部項目**，會另外跳出一個「尚未完成每日注意事項」的補提醒視窗（色調與當天主題色不同），之後每 10 分鐘再跳一次，直到所有項目都完成，主視窗與所有補提醒視窗才會一起自動關閉
- 每天會從指定的 11 種傳統色中隨機挽一個當作當天主題色，同一天固定不變，隔天自動重新挽選
- 全站字體使用 Arial（不加粗），畫面走圓角卡片、柔和色調的「動物森林」風格，不使用裝飾性小圖示
- 另外有一個「控制台」視窗，可以自由開關、調整提醒間隔、手動新增或刪除提醒事項、立即測試提醒效果

## 執行需求

- 電腦需安裝 Python 3（macOS / Windows / Linux 皮可，Python 內建的 tkinter 圖形庫已足夠，不需要另外安裝套件）
- 若不確定電腦是否有 Python，可在終端機（Windows 用「命令提示字元」或 PowerShell）輸入 python3 --version 或 python --version 檢查

## 執行方式

```
python3 health_reminder.py
```

Windows 若沒有 python3 指令，改用：

```
python health_reminder.py
```

執行後會看到一個小的「控制台」視窗，這個視窗可以自由縮小或關閉（關閉控制台會一併結束整個程式，因為排程是由它啟動的）；真正「無法關閉」的規則只套用在每小時跳出的提醒視窗本身。

## 想要每次開機自動啟動（選用）

**Windows：**
1. 開啟「工作排程器」(Task Scheduler)
2. 建立新工作 → 觸發程序選「登入時」→ 動作選「啟動程式」→ 程式路徑填 pythonw.exe，引數填 health_reminder.py 的完整路徑（用 pythonw.exe 可避免多跳出一個黑色命令視窗）

**macOS：**
1. 用「指令碼編輯程式」把啟動指令包成一個 .app，或
2. 建立一個 launchd 的 plist 檔案，登入時自動執行 python3 /完整路徑/health_reminder.py

## 想打包成不需要另外安裝 Python 的執行檔（選用）

可以使用 PyInstaller 在你自己的電腦上打包：

```
pip install pyinstaller
pyinstaller --onefile --windowed health_reminder.py
```

打包出來的執行檔會放在 dist 資料夾內，之後就可以直接雙擊執行，不需要再另外開終端機。

## 調整提醒事項

在控制台按「管理提醒事項」，可以新增或刪除提醒項目；新增時可以選擇這個項目是否需要計時，以及需要持續幾分鐘。所有設定都會存到你電腦裡的 ~/.health_reminder/config.json，下次開啟程式時會自動讀取。

## 已知限制

- 「視窗最下緣不能碰到工作列上緣」是透過移除系統標題列、持續保持最上層、並在拖曳時即時限制座標範圍來實現。在 Windows 上會直接讀取系統回報的每個螢幕工作區域（精準扣除工作列高度，並支援雙螢幕/多螢幕拖曳）；在其他作業系統上因無法直接取得工作列高度與各螢幕邊界，改採概略估算值（視為單一螢幕），屬於盡力而為的做法。
- 多螢幕拖曳（可以把視窗移到另一台螢幕上）目前是以 Windows API 精準判斷；在 macOS / Linux 上，視窗仍可在系統回報的「虛擬螢幕範圍」內拖曳，實務上是否能涵蓋到第二台螢幕會依作業系統與視窗管理员設定而異。
- 圓角效果是以 Tkinter 的 Canvas 繪製「圓角卡片」與「圓角按鈕」達成（整體介面的卡片、按鈕都是圓角），但外層視窗本身在少數平台上可能仍是直角邊框，這是 Tkinter 在跨平台狀況下的限制。
- 若關閉「控制台」視窗，整個程式（含排程）會一併結束；如果希望即使控制台被關閉，排程仍持續運作，可以告訴我，我可以再加上「最小化到系統匯」的功能。
